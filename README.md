# Spotify Web Player Clone

## Overview

A responsive Spotify-inspired web player interface developed using HTML5 and CSS3. This project recreates the desktop layout of Spotify with a focus on responsive design, clean UI components, and modern frontend development practices.

---

## Features

- Responsive Spotify-inspired user interface
- Sidebar navigation
- Sticky top navigation bar
- Music player layout
- Playlist and album cards
- Modern UI with hover effects
- Component-based page structure

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome

## Installation

Clone the repository

```bash
git clone https://github.com/sujal-sonawane/spotify-web-player-clone.git
```

Open the project folder and launch `index.html` in your web browser.
